# AquaWell UI polish - 2026-10-08

## What was improved

- Made notifications and recent activity messages more natural and user-friendly.
- Replaced technical wording such as database/Supabase failures with plain-language messages.
- Added friendly labels for activity types such as staff updates, payments, inventory, customers, and orders.
- Existing legacy notifications using `System Event: ...` are also converted to friendly titles when displayed.
- Changed the admin activity section from **System Audit Trail & Recent Activity Log** to **Recent Activity**.
- Changed **Live Cloud Database Sync** to **Updates appear automatically**.
- Changed **Mark read** to **Mark all as read** and the empty state to **You're all caught up.**
- Improved the global search placeholder to explain what can be searched.
- Updated the Change Password modal wording to be more natural.
- Fixed the toast layering issue: toasts now use `z-[11000]`, above the Change Password modal (`z-[10000]`). This lets password validation and password-update errors remain visible.
- Applied the toast layering fix to customer and staff dashboards as well for consistency.
- Added friendly backend-error handling so raw Supabase/API error text is not shown directly to users.

## Validation

- TypeScript check passed with `tsc --noEmit`.
- The existing project ESLint configuration still reports pre-existing issues across the project (mostly `any` usage and an existing React purity warning); these were not introduced by this UI polish.
- Vite build could not run in the supplied environment because the bundled `node_modules` is missing the platform-specific Rolldown native binding. Reinstall dependencies with `npm install` before running the normal build locally.
