# AquaWell targeted fixes — 2026-10-08

This package is based on the corrected AquaWell source package currently being used.

## Fixed

### 1. Customer order subtotal failure
- `aquawell_order_audit_fix.sql` replaces `place_customer_order` with a compatibility-safe implementation.
- It detects whether `order_items.subtotal` is a PostgreSQL generated column.
- If generated, the RPC does not explicitly insert `subtotal`.
- If it is a normal column, the RPC calculates and inserts `subtotal`.
- Stock, order, order item, and notification behavior are preserved.

### 2. Admin System Audit
- `AdminDashboard.tsx` now checks and reports audit insertion errors instead of silently ignoring them.
- `created_at` is explicitly supplied.
- The dashboard refreshes audit logs after successful insertion.
- Realtime INSERT events on `audit_logs` refresh the audit panel.
- `aquawell_order_audit_fix.sql` repairs the legacy audit trigger to safely normalize the text `timestamp` and timestamptz `created_at` fields.

### 3. Staff/Delivery dark mode
- `StaffDashboard.tsx` now reads the shared `ThemeContext` directly.
- The staff root explicitly uses the same slate dark palette as the other portals.
- Scoped legacy-surface CSS makes white/slate cards, borders, tables, inputs, and text transition consistently in dark mode.
- The change is scoped to the staff dashboard and does not alter other portal styling.

### 4. Mobile Staff/Delivery header
- Mobile header controls are now a clean equal-width grid.
- Staff gets four equal controls: Record Sale, Theme, Password, Logout.
- Delivery gets three equal controls: Theme, Password, Logout.
- Desktop remains an inline header.
- Branding is kept visible without forcing controls into a cramped two-column layout.

## Additional review findings

- Staff inventory module/state is not reintroduced.
- Change Password remains present.
- Delivery routing remains based on trusted application records.
- Customer/Staff account-management Edge Functions remain unchanged in this targeted package.
- No Auth tables are modified by the SQL patch.
- No business data is deleted by the SQL patch.
