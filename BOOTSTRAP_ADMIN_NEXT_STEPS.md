# After the first Admin is created

1. Log into AquaWell as `admin@aquawell.test` using the generated password.
2. Confirm routing goes to the Admin Dashboard.
3. Verify Dashboard, Inventory, Customers, Staff/Delivery, Orders, Sales, Reports/Forecast, Change Password, and dark mode.
4. Do not create other accounts until Admin login is confirmed.
5. Then create a Staff account through the normal Admin Dashboard flow.
6. Create a Delivery account through the same flow and verify it routes to the Staff/Delivery experience, not Customer.
7. Create a Customer account through the normal Admin Dashboard flow.
8. Test password changes and account deletion with test accounts only.
